# NextStep AI

Career guidance for Pakistani students. A student shares marks and interests, then sees career fields, universities, and scholarships that fit, with an AI counselor for the questions that follow.

The interface and front page are my part of the product. The application code lives in the team repository: [qandeel47/NextStep_AI](https://github.com/qandeel47/NextStep_AI).

## What the product does

- Career assessment from academic background, interests, skills, and preferences
- Career recommendations for that student
- Universities, programs, and scholarships in one place
- An AI career counselor for follow-up questions
- A clear next step instead of a generic list

The pitch deck describes a working full-stack MVP: a REST API, Django admin for careers, universities, and scholarships, and an AI service that can be switched off without taking the rest of the site down.
